\Hypertarget{index_md_README}%
 This library is developed to be of simple use, requiring only knowledgement on Bayesian filtering and object oriented C++ programming. It is contained in a single {\ttfamily \doxylink{bayesianfiltering_8hpp}{bayesianfiltering.\+hpp}} file.

It deals with both time varying linear and nonlinear discrete time models. For more details, see the documentation at {\ttfamily /doc} folder.\hypertarget{index_autotoc_md1}{}\doxysection{\texorpdfstring{Dependencies}{Dependencies}}\label{index_autotoc_md1}
The library was developed with little dependence on other libraries or operating system. Some dependencies vary according to the demos provided. See the corresponding {\ttfamily Readme.\+md} file.\hypertarget{index_autotoc_md2}{}\doxysubsection{\texorpdfstring{EIGEN}{EIGEN}}\label{index_autotoc_md2}
EIGEN is one of the most important libraries of linear algebra for C++. The Bayesian Filtering library relies strongly on it. Just install according to your system.\hypertarget{index_autotoc_md3}{}\doxysubsection{\texorpdfstring{Doxygen (optional)}{Doxygen (optional)}}\label{index_autotoc_md3}
Doxygen is an optional installation, only if you want to update the documentation (html and/or pdf).

Installation can be done in different operational systems. See Doxygen project at \href{https://www.doxygen.nl/}{\texttt{ https\+://www.\+doxygen.\+nl/}}

This library already has a Doxyfile configured at library root folter.

In the library root folder, run the following command\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{\$\ dogygen}

\end{DoxyCode}


This will generate documentation in html pages (doc/html) and source files for latex/pdf version (doc/latex).

In doc/html, open index.\+html in any browser.

In doc/latex, in order to generate the pdf documentation just run\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{\$\ make\ pdf}

\end{DoxyCode}
 This will compile latex sources and generate {\ttfamily doc/latex/refman.\+pdf} 

If latex and pdflatex are not installed in your system, install it.

For Linux, this can be accomplished by running\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{\$\ sudo\ apt\ install\ texlive-\/latex-\/base}
\DoxyCodeLine{\$\ sudo\ apt\ install\ texlive-\/fonts-\/recommended\ texlive-\/latex-\/extra}

\end{DoxyCode}


Or, if you have lots of disk space, just run\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{\$\ sudo\ apt\ install\ texlive-\/full}

\end{DoxyCode}
