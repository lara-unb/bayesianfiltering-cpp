\doxysubsection{Detailed Description}
Represents the parameters of a discrete time, generic nonlinear state space model\+: ~\newline
 

\begin{DoxyVerb}    x(k) = f(x(k-1),u(k),w(k)) {Process equation}

    y(k) = h(x(k),v(k)) {Measurement equation}
\end{DoxyVerb}
 with {\ttfamily x(k)} being state variables vector, {\ttfamily u(k)} measurement vector and {\ttfamily y(k)} measurement vector. Also, {\ttfamily w(k)} \texorpdfstring{$\sim$}{\string~} {\ttfamily N(0,\+Q)} and {\ttfamily v(k)} \texorpdfstring{$\sim$}{\string~} {\ttfamily N(0,\+R)} are respectively process and measurement noises.

This class contains only model parameters. It is a base virtual class, with computation of process and measurement equations as virtual member functions. Its definition should be done in a derived class at user side. Partial derivatives of process and measurement models should also be defined at a derived class. Some filters use such derivatives.

Initial state is a random variable following {\ttfamily x(0)} \texorpdfstring{$\sim$}{\string~} {\ttfamily N(\+X0,\+P0)} 

Also dim(x) = {\ttfamily Nx}, dim(u) = {\ttfamily Nu}, dim(y) = {\ttfamily Ny}, dim(w) = {\ttfamily Nw}, dim(v) = {\ttfamily Nv}. These dimensions should be first stablished by calling {\ttfamily Set\+Dimmensions()}, which make resizing of system parameters. After that, since parameters are public, they can be set at any time.

Angular measurements in radians need special treatment when computing innovation vector in filters using {\ttfamily atan2} function. In order to do this, {\ttfamily Y\+\_\+isangle} is used to indicate which components of {\ttfamily Y} are angles, which should be set as {\ttfamily true} by the user when initializing the model.

For the same reason, every change in state vector containing angles in some entries should me donne properly. Also, some filters compute covariance matrix from samples, requiring special treatment. Thus, {\ttfamily X\+\_\+isangle} is used to indicate which components of {\ttfamily x} are angles, which should be set as {\ttfamily true} by the user when initializing the model.
