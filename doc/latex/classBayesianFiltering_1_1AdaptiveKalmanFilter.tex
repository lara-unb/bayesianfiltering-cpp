\doxysubsection{Detailed Description}
Adaptive Kalman filter, with {\ttfamily Q} and {\ttfamily R} matrices changing when every measurement comes according two user supplied learning parameters. 

This implementation is specific for discrete time, continuous state models. ~\newline
