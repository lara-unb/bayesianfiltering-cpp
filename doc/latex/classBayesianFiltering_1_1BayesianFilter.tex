\doxysubsection{Detailed Description}
Base class of minimum variables of a Bayesian stochastic filter. All derived classes present filters for linear and nonlinear models. All filters follow the following loop. 


\begin{DoxyEnumerate}
\item Reset
\item Prediction\+: compute x(k\texorpdfstring{$\vert$}{|}k-\/1) using x(k-\/1) and input u(k)
\item Correction, in case of measurement available\+: compute x(k\texorpdfstring{$\vert$}{|}k) using x(k\texorpdfstring{$\vert$}{|}k-\/1) and measurement vector y(k);
\item In case of filter divergence, performe necessary actions and go back to step 1. Otherwise, go back to step 2.
\end{DoxyEnumerate}

As it can be seen, as described above correction is optional, which allows filter continuing by prediction. Internal member variables present the current filter state.

System model object should be not used in other purposes other than to be used as input to the filter. For the case of linear time varying models, it can have their parameters directly updated just before calling prediction/correction methods, as a way to deal with time varying systems. For the case of nonlinear time varying models, parameters updating is done in derived model class, where the methods are called from inside filter object. Thus, model updating is done in derived class, being not necessary to be done by the user.
